性能优化 脚本工具箱

收录 Android / 小米 / 红米常用性能优化脚本，分「免 root」与「需 root」两类。
一键复制 → 在手机终端 / adb 里粘贴执行，即可完成缓存清理、动画提速、调度优化等操作。

⚠️ 免责声明：脚本仅供学习与常规优化，部分命令需 root 权限、存在一定风险。执行前请先备份重要数据；涉及系统分区、删除系统应用的命令请谨慎使用。因误操作造成的后果需自行承担。
NO ROOT

免 root · ADB 命令

🎬关闭系统动画（流畅度提升）
ADB
把窗口、过渡、动画缩放全部设为 0，界面响应更跟手。想恢复把 0 改回 1。
adb shell settings put global window_animation_scale 0 adb shell settings put global transition_animation_scale 0 adb shell settings put global animator_duration_scale 0复制
🗑️清理全局缓存
ADB
清理系统各应用的缓存目录，释放空间。某些应用需重新登录。
adb shell pm trim-caches 2G复制
📉降低后台进程限制
ADB
限制后台进程数量，减少内存占用、降低发热。适合小内存机型。
adb shell settings put global background_process_limit 4复制
🧹清理日志缓冲区
ADB
清空 logcat 日志，释放系统存储与少量开销。
adb logcat -c复制
ROOT REQUIRED

需 root · 终端脚本

🧊清理 Dalvik / ART 缓存
需ROOT
清理 Dalvik 缓存（部分 ROM 适用），首次开机可能变慢属正常。
su -c "rm -rf /data/dalvik-cache/*" su -c "rm -rf /cache/dalvik-cache/*"复制
⚡调整 swappiness（内存交换倾向）
需ROOT
降低 swappiness 值，让系统优先使用物理内存，减少掉帧卡顿。数值越低越激进。
su -c "echo 60 > /proc/sys/vm/swappiness"复制
🔥设置 CPU 调度器（performance）
需ROOT
把可用核心切换到 performance 调度，提升流畅度（代价是更耗电发热）。
for cpu in /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor; do su -c "echo performance > $cpu" done复制
🧊清理日志与临时文件
需ROOT
清理系统临时目录，释放空间（不会动你的照片和文件）。
su -c "rm -rf /data/tmp/* /data/local/tmp/* /cache/* 2>/dev/null"复制
🚀强制释放内存（drop caches）
需ROOT
立即回收页面缓存，效果是「变相清内存」，适合游戏前执行。
su -c "sync && echo 3 > /proc/sys/vm/drop_caches"复制
HOW TO USE

怎么执行

🖥️ 方式一 · 电脑 ADB（免 root）

手机开启「开发者选项 → USB 调试」，连接电脑，在电脑装好 adb 后，把上面「ADB」类命令直接粘贴到命令行回车即可。

📱 方式二 · 手机终端（需 root）

已 root 的手机用 MT管理器终端 / Termux（先 su）或 KernelSU/Magisk 自带终端，把「需 root」脚本整段粘贴回车。

📦 方式三 · 刷入模块（进阶）

也可以把脚本写成 service.sh 打包成 Magisk 模块，开机自动执行——适合想长期生效的调度优化。
